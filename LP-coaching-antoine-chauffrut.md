# Landing page coaching d'Antoine Chauffrut

## En bref

- **Quoi** : textes (`texts.json`) et images (favicons, images de partage) de la landing page de coaching d'Antoine Chauffrut, coach de dirigeants et psychologue du travail.
- **Activité** : Cozac Conseil (client, lié au club Sillage).
- **Pilotage** : COSMIC, `projets/sillage.md`.

## Contenu

- `texts.json` : tous les textes de la page (hero, à propos, offres, appel à l'action).
- `Social.png`, `Social2.png` : images de partage sur les réseaux.
- `favicon.png`, `favicon48.png` : icônes.

Le code de la page n'est pas dans ce repo. Les deux versions précédentes (`Antoinechauffrut`, `Antoinechauffrutcoaching`) sont archivées sur GitHub depuis le 24/11/2026.

Repo public : n'y mettre ni donnée personnelle ni information de pilotage.
